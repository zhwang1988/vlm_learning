# Day 8 · 客服数据 Taxonomy 设计

> 预计 3–4h ｜ 📓 `notebooks/day-08_taxonomy_matrix.ipynb` ｜ 💻 `src/data/taxonomy.py`
> 今天**不写模型代码**，写的是整个项目的地基：数据长什么样由你今天决定。

## 今日目标（一句话）

设计「8 大意图 × 6 类图像」的数据矩阵，每个格子标注目标样本量，
并为每个意图亲手写下至少一个真实对话样例。

## 一、读（60 min）

- `docs/05-data-engineering.md` 第 4 节（taxonomy 设计 + 难度分层）
- 逛 30 分钟电商平台（淘宝/京东/拼多多）客服页，**收集真实问法** —— 这是今天的作业核心

## 二、写（100 min）

`src/data/taxonomy.py`（骨架已给）：

| 项 | 内容 | 你的动作 |
|---|---|---|
| `INTENTS`（8 个） | 尺码咨询 / 材质工艺 / 库存物流 / 质量瑕疵 / 退换货 / 搭配建议 / 优惠活动 / 转人工 | 逐个确认定义边界，歧义的加注释 |
| `IMAGE_TYPES`（6 个） | 商品图 / 上身图 / 瑕疵特写 / 尺码表 / 快递单 / 聊天截图 | 同上 |
| `TARGET_DISTRIBUTION` | 8×6 矩阵的样本量配比 | 按真实客服分布改（尺码/物流最多，转人工最少） |
| `DIFFICULTY_TIERS` L1–L4 | 简单单图问答 → 多图多轮+推理 | 每级写 1 个例子 |
| `build_generation_plan` | 从矩阵生成合成任务清单 | 跑通即可 |

**关键动作**：矩阵每个非零格子，去电商平台找一个真实对话例子记下来。
找不到真实例子的格子 = 你拍脑袋造的伪需求，直接把配量调到 0。

## 三、跑（本地）

```bash
python -m src.data.taxonomy          # 打印矩阵 + 导出 JSON
make data-plan                       # 同上（Makefile 别名）
jupyter lab                          # notebooks/day-08_taxonomy_matrix.ipynb
```

期望：一张 8×6 表格 + 总量统计（默认 10k）。改 `TARGET_DISTRIBUTION` 后总量随之变化。

## 四、验收清单

- [ ] 矩阵每格有样本量，行合计/列合计合理（无明显孤岛）
- [ ] 每个意图 ≥ 1 个**真实收集**的对话例子（记录来源链接/截图）
- [ ] 能回答：为什么「转人工」也要合成数据？（答：模型要学会**识别自己不会**）
- [ ] `export()` 出的 JSON 已存 `data/taxonomy_plan.json`

## 五、容易踩的坑

1. **意图边界重叠** —— 「什么时候发货」是库存物流还是优惠活动？定一条裁决规则写进注释。
2. **配比头重脚轻** —— 全是小样本长尾意图，Day 9 合成费用会爆炸。
3. 别忘了**负样本**：模型要见过「图里没有的信息」，才会拒答而不是编（配 L3 层 10%）。
